# Support

Omni.Blazor is maintained as an open source project. Community support is
best-effort and does not include a guaranteed response time.

## Before Asking for Help

1. Update to the latest stable package version when practical.
2. Check the [README](README.md), [live component showcase][showcase], and the
   generated [`llms.txt`](llms.txt) or [`docs/components.json`](docs/components.json)
   catalog before relying on an undocumented parameter or behavior.
3. Search [existing issues][issues] for the same symptom or use case.
4. Reduce the problem to the smallest component and configuration that still
   reproduces it.

## Where to Ask

- **Usage question:** open the [usage question form][question] and include the
  package version, goal, minimal code, and what you already tried.
- **Reproducible defect:** use the [bug report form][bug] and include complete
  reproduction steps and environment details.
- **Feature or API proposal:** use the [feature request form][feature] and
  describe the user problem independently from the proposed implementation.
- **Security vulnerability:** do not open a public issue. Follow the private
  reporting instructions in [SECURITY.md](SECURITY.md).
- **Contribution workflow:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Please do not include credentials, access tokens, customer data, or other
sensitive information in public issues or reproductions.

## Scope of Support

The project can help with supported Omni.Blazor packages, the component
manifest and MCP tool, and repository examples. General application debugging,
custom product implementation, unsupported package versions, and third-party
framework issues may require a minimal reproduction that isolates the behavior
to Omni.Blazor before maintainers can investigate.
